Under the Hood

How ClipLAN Works

A peek at the powerful networking engine that makes blazing-fast local sharing possible.

📡
01

Zero-Config Discovery

Devices find each other instantly using UDP multicasting on port 53317. Heartbeat packets broadcast every 2 seconds with device metadata. No manual setup required.

🤝
02

Firewall-Bypassing Handshake

Unicast laser-beam responses bypass client isolation. If Device A hears even one broadcast from Device B, it fires a direct unicast response — defeating strict routers instantly.

📦
03

Transfer Approval

When you tap Send, a TCP connection opens. The receiver gets a beautiful approval modal showing file names, sizes, and types. Accept or decline with one tap.

🚀
04

Zero-Copy Streaming

Files stream in efficient 2MB chunks over raw TCP sockets on port 53318. Bytes flow directly from NIC to disk — completely bypassing the Dart VM's garbage collector.

🧠
05

OOM Backpressure

When Wi-Fi outpaces disk write speed, a dynamic flush algorithm kicks in at 10MB intervals. RAM stays flat — transfer a 1TB file on a 2GB RAM device.

✅
06

SHA-256 Verification

Chunked cryptographic conversion runs in parallel with writes. The final hash is compared byte-by-byte. Corrupted files are auto-deleted — zero tolerance for bad data.

📶
07

Centralized WiFi Router Transfer

When devices connect to the same WiFi router — whether at home, office, or university — ClipLAN auto-discovers every peer on the subnet. Files route through the centralized access point at full LAN bandwidth. No internet needed — just a shared router.

Technical Architecture

Built with Cutting-Edge Technology

Every component is chosen for maximum performance, reliability, and cross-platform compatibility.

🎯

Flutter & Dart (AOT Compiled)

Compiles ahead-of-time to native ARM/x86 machine code. 60-120 FPS animations run smoothly even during heavy I/O operations. Direct C-level socket bindings via dart:io.

📡

UDP Discovery Engine (Port 53317)

Multi-cast heartbeat to 255.255.255.255, subnet broadcast, and multicast groups 224.0.0.1 & 224.0.0.251. Resilient garbage collection with 15-second timeout.

⚡

TCP Transfer Engine (Port 53318)

Raw TCP streaming with length-prefixed JSON control frames. Zero-copy architecture using IOSink.add() with dynamic backpressure flushing at 10MB intervals.

🔐

SHA-256 Chunked Verification

Real-time cryptographic checksum using startChunkedConversion() sink. Hash is computed in parallel with disk writes — zero performance overhead.

💾

Hive NoSQL Persistence

Pure-Dart key-value store operating in-memory with async disk sync. Lightning-fast reads of transfer history — no SQL joins, no locking delays.

🔒

Hardware WakeLock Control

Active CPU wakelock during transfers. Wi-Fi radio stays at max voltage even with screen off. Auto-releases on transfer completion.

macOS Installation Guide

Because ClipLAN is a free, open-source application distributed outside the Mac App Store, macOS Gatekeeper may show a warning that it "cannot be verified". This is completely normal.

To bypass this warning:

  1. Drag ClipLAN into your Applications folder.
  2. Do not double-click it. Instead, Right-click (or Control-click) the ClipLAN app.
  3. Select "Open" from the context menu.
  4. The warning will appear again, but this time it will have an "Open" button. Click it.

Note: You only need to do this the very first time. Afterward, you can double-click it normally!
