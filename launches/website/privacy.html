Privacy Policy

Last updated: August 22, 2026

🛡️ ClipLAN is a 100% offline, serverless application. We do not collect, store, transmit, or process any personal data whatsoever.

1. Introduction

Welcome to ClipLAN ("the App", "we", "us", "our"). This Privacy Policy explains how information is handled when you use our peer-to-peer file sharing and clipboard application. Your privacy is paramount to us — which is precisely why we built ClipLAN to operate without any cloud infrastructure.

2. Information We Collect

None. ClipLAN operates entirely offline on your local network (LAN). We have zero servers, zero analytics, zero tracking pixels, and zero data collection infrastructure.

Specifically, ClipLAN does NOT collect:

  • Personal identification information (name, email, phone)
  • Device identifiers or advertising IDs
  • Usage analytics or behavioral data
  • Files, content, or clipboard data you transfer
  • Location data or GPS coordinates
  • Cookies, tokens, or session data
  • Network metadata beyond what is required for local discovery

3. Local Network Operations

ClipLAN uses your device's local network capabilities exclusively for peer-to-peer functionality:

  • UDP Discovery (Port 53317): ClipLAN broadcasts small JSON packets containing your device name and platform type on your local network to discover nearby devices. These packets never leave your local router.
  • TCP File Transfer (Port 53318): Files are streamed directly between devices on the same local network. No data is ever routed through external servers.
  • Clipboard Sharing: Text snippets are sent directly between devices via UDP broadcast or TCP unicast — never stored externally.

4. Device-Local Storage

ClipLAN stores the following data only on your device using Hive NoSQL:

  • Your chosen device name (for display to other users on the network)
  • Transfer history (file names, sizes, timestamps — stored locally only)
  • Your clipboard snippets (stored locally only)
  • App settings and preferences

This data is never transmitted to any server, cloud, or third party. You can clear all stored data from within the app's Settings screen at any time.

5. Permissions

ClipLAN requests the following operating system permissions:

  • Local Network / Nearby Wi-Fi Devices: Required for UDP/TCP peer discovery and file transfer. This permission does not grant internet access.
  • Storage / File Access: Required to read files you select for sending and to save received files to your Downloads folder.
  • WakeLock: Prevents the device from sleeping during active file transfers to ensure transfer stability.

6. Third-Party Services

ClipLAN does NOT use any third-party services, SDKs, or analytics libraries that collect user data. There are no ads, no tracking pixels, no Firebase Analytics, no Crashlytics, and no telemetry of any kind.

7. Data Security

All file transfers are verified using SHA-256 cryptographic checksums to ensure data integrity. However, transfers occur over your local network and are not encrypted end-to-end. We recommend using ClipLAN only on trusted networks.

8. Children's Privacy

ClipLAN does not collect any personal information from anyone, including children under 13. The app is safe for users of all ages.

9. Changes to This Policy

We may update this Privacy Policy from time to time. Any changes will be posted on this page with an updated revision date. Since ClipLAN has no server-side component, we cannot push policy update notifications — please check this page periodically.

10. Open Source

ClipLAN is open-source software. You can inspect, audit, and verify every line of code to confirm that no data collection occurs. We believe in full transparency.
