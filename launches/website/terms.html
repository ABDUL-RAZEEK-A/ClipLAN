2. Description of Service

ClipLAN is an open-source, peer-to-peer (P2P) file sharing and real-time clipboard application. The App operates entirely on local area networks (LAN) without any internet connectivity, cloud servers, or centralized infrastructure. Key functionalities include:

  • Discovering nearby devices on the same local network via UDP multicast
  • Transferring files of any size directly between devices via TCP sockets
  • Sharing clipboard text across devices in real-time
  • Verifying file integrity with SHA-256 cryptographic checksums
  • Maintaining transfer history locally on the device
